Shorts Uploader

Ferramenta pessoal usada para enviar e agendar os vídeos curtos (YouTube Shorts) de um único canal de curiosidades, administrado pelo próprio dono da ferramenta.

Ela usa a YouTube Data API apenas para enviar vídeos ao canal do próprio dono e consultar o status desses envios. Não é oferecida a outros usuários.
