▶ Uses YouTube API Services

Privacy Policy — Shorts Uploader

Last updated: November 12, 2026.

YouTube API Services

Shorts Uploader uses YouTube API Services. By using it, you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

What the tool does

Shorts Uploader is a private desktop tool that runs on its owner's computer and uploads videos to the owner's own YouTube channel. It has a single user: the owner.

Data accessed, used and stored

  • youtube.upload: upload videos (with title, description and tags written by the owner) to the authorized channel.
  • youtube.readonly: read the authorized channel's title and the status of uploaded videos.
  • The OAuth token is stored only on the owner's computer (a local file). The YouTube video ID and scheduled time of each upload are kept in a local log.

Sharing

No data is sent to any server other than Google's, and nothing is sold or shared with third parties. The tool does not collect data about any other person. No cookies or tracking are used, and there is no advertising.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deleting data

  • Access can be revoked at any time on the Google security settings page: security.google.com/settings/security/permissions.
  • Deleting the local token file removes all stored credentials immediately. Locally stored API data (video IDs and schedule) is deleted on request or when the tool is uninstalled, and is never kept longer than 30 days after access is revoked.
